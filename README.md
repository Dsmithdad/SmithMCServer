# Smithserver

Minecraft Java 1.21 · Fabric · Creative

**Join page:** https://dsmithdad.github.io/SmithMCServer/

1. Download a pack from the [latest release](../../releases/latest) — *Smithserver-Required* (minimum) or *Smithserver-Full* (adds Sodium, Iris, Xaero's maps, shaders).
2. Import the `.mrpack` into the [Modrinth App](https://modrinth.com/app) or [Prism Launcher](https://prismlauncher.org).
3. Add the server address shown on the join page and play.
