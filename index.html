2 · Install in 4 steps

  1. Install the free Modrinth App (or Prism Launcher) and sign in with your Minecraft account.
  2. Download one pack above: Standard, or Standard + Extras.
  3. In the launcher: Add instance → Import from file and pick the .mrpack. It installs everything for you.
  4. Launch, go to Multiplayer → Add Server, paste the address above, and join.
Changed your mind? Just import the other pack as a second instance. They don't interfere with each other. Turn shaders on in Options → Video Settings → Shader Packs.
